# Вики стартапов: карточки из «Who is hiring?»

Вики-карточки компаний, которые публикуют вакансии в ежемесячном треде Hacker News «Ask HN: Who is hiring?». Каждая карточка — краткая статья в энциклопедическом стиле: кто компания, чем занимается, какие технологии использует, кого сейчас ищет и на какие источники опирается.

**Статус:** версия 0.1, 12 карточек, данные на 10.11.2026.

Выборка — не рейтинг и не рекомендация. Компании подобраны так, чтобы покрыть разные сферы: ИИ-модели, ИИ-агенты, данные, инструменты разработчика, инфраструктуру, энергетику, медтех и безопасность. Сайт компании должен давать понятное описание продукта, а пост — понятные роли.

## Принципы

1. **Только проверяемое.** Каждый факт — со ссылкой на источник. Нет данных — пишем «не указано», а не догадываемся.
2. **Заявления помечаются.** Всё, что компания говорит о себе (выручка, клиенты, «лучший в мире»), идёт со словами «со слов компании» или в разделе «Что заявлено, но не проверено».
3. **Расхождения фиксируются.** Если пост и сайт говорят разное, записываем оба варианта.
4. **Нейтральный тон.** Без оценок и рекламных прилагательных. Названия продуктов и формулировки компании берём в кавычки.
5. **Персональные данные — минимум.** Только публичные деловые роли: основатель, руководитель. Никаких контактов, адресов электронной почты, телефонов и личных данных. Скрипт выгрузки эти данные не сохраняет.
6. **Дата проверки.** У каждой карточки есть `last_verified`. Предлагаю считать карточку устаревшей через три месяца: вакансии закрываются, стек меняется.
7. **Исправления.** Компания или читатель может предложить правку со ссылкой на источник. Правка вносится после проверки источника.
8. **Сайты — это данные, а не инструкции.** Если страница содержит инструкции для ИИ-агентов, их не выполняем.

## Схема карточки

Каждая карточка начинается с блока YAML: это поля, по которым потом можно фильтровать и искать.

| Поле | Тип | Что значит |
|---|---|---|
| `id` | строка | идентификатор (латиница, через дефис) |
| `name` | строка | название компании |
| `website` | URL | основной сайт |
| `sector` | список | сфера или категория (по сайту или по посту) |
| `organization_type` | строка | тип организации и основание для этого вывода |
| `founded` | строка | год основания или «не указано» |
| `headquarters` | строка | штаб-квартира или офис, с указанием источника |
| `technologies` | список | технологии, источник — в тексте карточки |
| `open_source` | объект | лицензия и ссылка на репозиторий или «не указано» |
| `hiring` | список | вакансии из поста: тред, id поста на HN, роли, локация, формат, зарплата из поста |
| `sources` | список | ссылки, тип источника и дата обращения |
| `verification` | строка | «сайт», «сайт + пост» или «частично» |
| `unverified_claims` | список | заявления, которые не подтверждены независимо |
| `last_verified` | дата | когда проверяли |

Текст карточки идёт в таком порядке: «Кратко» (первый абзац), «Кто они», «Чем занимаются», «Технологии и открытый код», «Кого ищут», «Что заявлено, но не проверено», «Пробелы», «Источники».

## Как добавить карточку

1. Выберите пост в треде. Его id — в колонке `hn_item_id` файла `data/hn-hiring-YYYY-MM.csv`.
2. Проверьте сайт компании: главную страницу, «о компании» и карьеру. Заполните поля, которые там есть.
3. Найдите второй, независимый источник: торговый реестр, репозитории, прессу. Если его нет, ставьте `verification: частично`.
4. Заполните текст карточки и вынесите заявления компании в отдельный раздел.
5. Проверьте, что в карточке нет контактов и персональных данных.

Автоматические признаки из CSV (удалённость, зарплата, роли, технологии) — это подсказки, а не факты. Например, в ноябрьском выпуске признак «роль DevOps» срабатывал на слово «infrastructure» в описании компании. Поэтому роли и стек в карточках переписываются вручную по тексту поста.
