# Zed Industries

> **Почему в выборке:** редактор кода на Rust, который компания связывает с работой ИИ-агентов. Показательный пример категории «инструменты разработки».

**Zed Industries** делает редактор кода Zed — быстрый редактор на Rust для macOS, Linux и Windows. По описанию компании, он рассчитан на совместную работу людей и ИИ: параллельный запуск агентов, предсказание правок, совместное написание кода. Отдельный продукт **Delta** (публичная бета) — многопользовательская среда для работы с кодом и агентами. Компания пишет, что замена pull request'ов — её первый шаг к замене GitHub.

Аудитория — разработчики и команды. Основатели, по подписям под письмом команды на сайте и по странице команды (CEO & Co-founder и Co-founder): Nathan Sobo, Antonio Scandurra, Max Brunsfeld.

## Технологии и открытый код

- Язык и архитектура: Rust. Интерфейс использует GPU, для этого есть собственная библиотека GPUI (по сайту, GPU-ускоренный UI-фреймворк для Rust).
- Интеграции: LSP, DAP (отладка), ACP (агенты Claude Agent, Codex, OpenCode), MCP-серверы, REPL через ядра Jupyter, удалённая разработка (интерфейс на машине разработчика, код на сервере).
- Модель предсказания правок Zeta2 распространяется с открытыми весами (по сайту).
- Репозиторий: github.com/zed-industries/zed — ссылка с сайта (кнопка GitHub / Clone source). Лицензия в собранных источниках не указана.
